# Kiwi Brain Quest

A lightweight bilingual (Korean/English) maths practice game for Years 1–6.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `kiwi-brain-quest`).
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save. The URL will appear in the Pages settings after deployment.

## Features
- Year 1–6 selection
- Korean / English interface
- Topic selection: Number, Algebra & Patterns, Measurement, Geometry & Space, Statistics & Data, Probability
- Normal mode (10 questions) and unlimited Speed mode
- Separate timer difficulty (15 / 10 / 6 seconds)
- Speed-mode adjustment of the *next question's* maths difficulty
- Pause timer without hiding the question
- Explanations after answers and extended explanations after timeout
- Responsive layout for mobile and desktop

## Curriculum note
The topics and progression are inspired by the New Zealand Curriculum's Mathematics and Statistics learning area. This is a practice prototype, not an official Ministry of Education resource or a complete representation of every year-level achievement objective. Please review and adapt question banks with a qualified NZ educator before classroom or assessment use.
